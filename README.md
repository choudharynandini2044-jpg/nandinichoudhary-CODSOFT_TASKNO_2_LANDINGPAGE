# NovaTech Landing Page

A modern, responsive, production-quality landing page built with HTML5, CSS3, and vanilla JavaScript (ES6+).

## Features
- Sticky responsive navbar with mobile hamburger menu
- Hero section with gradient visuals and CTAs
- About section with mission, vision, and core values
- Services feature cards with hover animations
- Feature highlights and performance stats
- Animated statistics counters
- Testimonials section
- 3-tier pricing with recommended plan highlight
- Contact form with frontend validation and success/error messages (frontend demo)
- Footer with social links and copyright
- Scroll-reveal animations and smooth scrolling
- Fully responsive (desktop, tablet, mobile)

## Setup & Run
No build step required. Open `index.html` directly in your browser, or serve locally:

```bash
# Using Python
python -m http.server 8080

# Or using Node (npx)
npx serve .
```

Then visit http://localhost:8080.
